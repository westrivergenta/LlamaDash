# ラマダッシュ

ラマを操作して障害物をよけ、宝石を集める横スクロールのランゲームです。スマホのホーム画面に追加してアプリとして遊べ、一度開けばオフラインでも動きます。

- タップでジャンプ、長押しで大ジャンプ
- 記録は「宝石のポイント＋走った距離(m)」の合計
- 自己ベストと全体ランキングを表示（ランキングは Supabase を使用）
- オフライン中に出した自己ベストは端末に保存し、オンラインに戻ったときに自動でランキングへ送信

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | ゲーム本体（HTML・CSS・JavaScript） |
| `config.js` | ランキングサーバーの接続設定 |
| `sw.js` | Service Worker（オフライン対応） |
| `manifest.webmanifest` | アプリ名・アイコンなどの設定 |
| `icons/` | アプリアイコン（192・512・マスカブル512・Apple 180・ファビコン32） |
| `audio/start.mp3` | スタート時に流す音楽（流し始めてから3秒後にゲーム開始） |
| `supabase/schema.sql` | ランキング用のテーブルと関数 |

## 公開手順

### 1. GitHub Pages で公開する

1. GitHub で新しいリポジトリを作り、このフォルダの中身をすべてアップロードします（`index.html` がリポジトリの一番上に来るように）。
2. リポジトリの **Settings → Pages** を開き、**Source** を「Deploy from a branch」、ブランチを `main`、フォルダを `/ (root)` にして保存します。
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べます。

この時点ではランキングは「未設定」と表示され、自己ベストだけが記録されます。

### 2. ランキングを有効にする（Supabase）

1. [Supabase](https://supabase.com/) に登録し、新しいプロジェクトを作ります（無料プランで動きます）。
2. 左メニューの **SQL Editor** を開き、`supabase/schema.sql` の中身を貼り付けて **Run** します。
3. **Project Settings → API**（または **API Keys**）で次の2つをコピーします。
   - Project URL（例：`https://abcdefghijklmnop.supabase.co`）
   - 公開用のキー：`anon` `public` キー、または `sb_publishable_` で始まる Publishable key
4. `config.js` の `SUPABASE_URL` と `SUPABASE_ANON_KEY` に貼り付け、GitHub にアップロードし直します。
5. `sw.js` の `VERSION` を1つ上げます（次の「更新するとき」を参照）。

公開用のキーはブラウザに見えても問題ない種類のキーです。`service_role` や `sb_secret_` で始まる秘密のキーは絶対に `config.js` に入れないでください。

### 3. 更新するとき

ゲームはオフライン用に端末へ保存されるため、ファイルを差し替えたら **`sw.js` の `const VERSION = 'v1';` を `v2`、`v3`…と必ず上げてください**。上げないと、遊ぶ人の端末に古い版が残り続けます。新しい版は、更新後に一度開いたあと、次に開いたときから反映されます。

## ランキングの仕組み

- 各端末は最初に「書き込み用の秘密ID」と「表示用の公開ID」を作り、端末に保存します。秘密IDは外に出ないので、他の人の記録は書き換えられません。
- 送信は `submit_score` 関数経由のみで、サーバー側で「今より高いときだけ更新」します。オフライン中の記録を後から送っても、古い記録で上書きされることはありません。
- 送信のタイミング：ゲームオーバー時、オンラインに戻ったとき、アプリを前面に戻したとき、未送信があるあいだ1分ごと。
- ランキングは上位50件を取得し、上位20件と自分の順位を表示します。最後に取得したランキングは端末に保存され、オフラインでも「○時点」として表示されます。
- ニックネームはランキング画面で変更できます（最大12文字）。

## 注意

- **不正対策について**：ブラウザだけで動くゲームのため、技術のある人が偽のスコアを送ることは完全には防げません。極端な値（1000万超）や不正な名前はサーバー側で弾きます。気になる記録は Supabase の **Table Editor** の `scores` テーブルから削除できます。
- **Supabase の無料プラン**は、1週間アクセスがないとプロジェクトが一時停止します。停止中はランキングが「オフライン中」と表示され、自己ベストは端末に保存されて、再開後に送信されます。管理画面から再開できます。
- **フォント**は Google Fonts から読み込みます。初回にオンラインで開いたときに端末に保存され、以降はオフラインでも使われます。
- 端末のデータ（自己ベスト・名前・ID）はブラウザごとに保存されます。ブラウザのデータを消すと、別の人として扱われます。
